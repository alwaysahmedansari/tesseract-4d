# Tesseract 4D

An interactive 3D experience built with Three.js and GSAP. A real four-dimensional hypercube rotates through the fourth axis and projects into 3D, inside an infinite twisting tunnel.

**Live demo:** https://YOUR-USERNAME.github.io/tesseract-4d/

## Controls
- Drag: rotate the fourth axis
- Shift Gravity button or double-tap: warp and flip the world 90°

## Tech
- Three.js (r128) for WebGL rendering
- GSAP for animation
- Single file, no build step

## Run locally
Download `index.html` and open it in any modern browser.
